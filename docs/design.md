# 模型設計

## 目標

1. **理論隨機抽樣（SRS）**：驗證理論誤差範圍（±3%）。
2. **系統性偏差**：模擬 Coverage Bias / Non-response Bias，特別是不同年齡層接聽率差異造成的統計失真。
3. **加權還原（Raking / IPF）**：量化加權的修正極限與權重爆炸現象。
4. **平行運算**：為大規模蒙地卡羅敏感度分析與多執行緒（Thread-pool / TBB / OpenMP）預留架構。

## 母體設定（第一階段）

為避免「假精緻」與維度詛咒，第一階段只使用三個人口統計維度：年齡、地區、性別。三者假設彼此獨立。

**年齡層**

| 年齡層 | 母體佔比 | 支持 DPP | 支持 KMT | 不表態 | 市話接聽率 |
|---|---|---|---|---|---|
| Young (20–39) | 30% | 65% | 25% | 10% | 5% |
| Middle (40–59) | 35% | 45% | 40% | 15% | 30% |
| Senior (60+) | 35% | 30% | 55% | 15% | 60% |

支持 KMT 與不表態的比例為暫定值。

**其他維度**

- **Region**：North 45%、Central 25%、South 27%、East 3%
- **Gender**：Male 49%、Female 51%

目前投票傾向只與年齡有關，地區與性別不影響投票傾向。

**接聽率**以 `[年齡][候選人]` 為索引，市話（`response_rate`）與手機（`mobile_response_rate`）分開設定：

- 同一年齡層各候選人的接聽率相同時，接聽只與年齡有關（MAR），依年齡加權即可修正偏差。
- 接聽率依投票意向而不同時（MNAR），加權無法完全修正，可用來觀察加權的極限。
- 手機接聽率預設為 Young 20%、Middle 25%、Senior 30%，各候選人相同（MAR），數值為暫定值。

**電話涵蓋**：每位選民另有兩個屬性，決定能否被各種電話調查抽到。

- `has_landline`：是否有市話，機率為 `landline_share[年齡][候選人]`。預設全部為 1.0（每人都有市話），此時市話調查的結果與加入此屬性前完全相同。
- `phones`：手機數量 0 到 `kMaxPhones`（3，代表 3 支以上），分布為 `phone_share[年齡][候選人]`，數值為暫定值。預設同一年齡層中 DPP 支持者擁有較多手機，造成年齡加權無法修正的多重性偏差；沒有手機的比例則只與年齡有關（Young 1%、Middle 2%、Senior 10%）。
- 沒有市話的人不會被市話調查抽到，0 支手機的人不會被手機調查抽到，形成涵蓋偏差；這和「抽到但不接」的無回應偏差是不同機制。
- 簡化假設：真實的市話是一戶共用一支，家中人數越多，每人被抽中的機率越低；這裡假設每位有市話的人各有一支號碼。

這兩個屬性使用由母體 seed 衍生的另一條亂數序列產生，因此修改相關參數不會改變年齡、地區、性別與投票傾向。

所有參數集中在 `include/poll_sim/params.hpp`：

- `PopulationParams`：母體大小、各維度比例、投票傾向、接聽率、市話擁有率、手機數量分布、手機接聽率、母體 seed。
- `SimParams`：要測試的樣本數清單 `sample_sizes`、重複次數 `replications`、抽樣 seed。

母體與抽樣使用不同的 seed，可以固定母體、只改變抽樣。

## 模擬流程

1. 依 `PopulationParams` 生成合成選民母體。
2. 從母體實際計算各候選人的真實支持率與年齡比例，作為比較基準（不使用參數的理論值）。
3. 對每個樣本數 n，各抽樣方法重複執行 `replications` 次民調。
4. 每次民調以不同估計方法算出支持率與標準誤，彙整成統計表。

同一抽樣方法的各種估計方法共用同一批民調樣本，差異只來自估計方法。

## 抽樣方法

| 方法 | 說明 |
|---|---|
| SimpleRandom | 不重複隨機抽出 n 人，抽到重複就重抽；每個人都回答（理想情況） |
| Landline | 從市話名單中不斷隨機撥打未撥過的號碼，每人依 `response_rate[年齡][候選人]` 決定是否接聽，直到湊滿 n 位受訪者；拒接者不會再被撥打 |
| Mobile | 同 Landline，但從手機名單撥打，接聽率為 `mobile_response_rate[年齡][候選人]` |

市話與手機共用同一段撥號邏輯，只差在名單、接聽率與設計權重。

- 未撥過的是「號碼」而不是「人」：有多支手機的人拒接一個號碼後，仍可能經由另一個號碼被撥打，並重新決定是否接聽。
- 同一人經由不同號碼接聽兩次時，兩次回答都計入樣本，並記錄為重複受訪（實際的民調通常無法辨識）。

**抽樣底冊（電話號碼名單）**：名單的第 k 筆記錄號碼 k 屬於哪位選民（母體索引），由母體直接推導。

- 市話名單：每位有市話的選民一筆。
- 手機名單：每支手機一筆，有 k 支手機的選民出現 k 次，被抽中的機率也是 k 倍（預設參數下約 1,148 萬筆）。

## 估計方法

| 方法 | 估計值 | 標準誤 |
|---|---|---|
| 未加權 | 樣本中的支持比例 p | √(p(1−p)/n) |
| 年齡加權（post-stratification） | Σₐ Wₐ · pₐ | √(Σₐ Wₐ² · pₐ(1−pₐ)/nₐ) |

- Wₐ：母體中年齡層 a 的比例；pₐ、nₐ：樣本中年齡層 a 的支持比例與人數。
- 某年齡層沒有受訪者時，略過該層，並將其餘年齡層的 Wₐ 重新正規化。
- Kish 有效樣本數：每位年齡層 a 的受訪者權重為 Wₐ/nₐ，有效樣本數 = (Σw)²/Σw² = 1 / Σₐ(Wₐ²/nₐ)。

**設計權重**：每位受訪者帶有一個設計權重 w。SimpleRandom 與 Landline 為 1；Mobile 為多重性權重 1/手機數，抵銷手機多的人較容易被抽到。目前直接使用真實的手機數量（受訪者不會誤報）。`tally` 依 `[年齡][候選人]` 累計 Σw，並依年齡層累計 Σw²。

| 方法 | 估計值 | 標準誤 |
|---|---|---|
| 多重性加權 | Σw·y / Σw | √(p(1−p)/n_eff)，n_eff = (Σw)²/Σw² |
| 多重性 + 年齡加權 | Σₐ Wₐ · pₐ，pₐ 為年齡層 a 內的加權比例 | √(Σₐ Wₐ² · pₐ(1−pₐ)/n_eff,ₐ) |

- y：受訪者是否支持該候選人（1 或 0）；n_eff,ₐ：年齡層 a 內的 Kish 有效樣本數 (Σw)²/Σw²。
- 標準誤使用 Kish 近似，忽略權重與投票意向的相關性；較精確的線性化（Taylor）變異數留待之後實作。
- 權重全部為 1 時，兩者分別等於未加權與年齡加權估計。
- 多重性 + 年齡加權的有效樣本數為 1 / Σₐ(Wₐ²/n_eff,ₐ)。

## 程式架構

| 模組 | 職責 |
|---|---|
| `types` | `AgeGroup`、`Region`、`Gender`、`Candidate` 列舉與 `to_string` |
| `voter` | 選民結構 `Voter`（人口屬性、投票傾向、市話與手機數量） |
| `params` | `PopulationParams`、`SimParams` 與參數驗證 |
| `population` | `generate_population`：依參數生成母體 |
| `sampling` | `SamplingMethod`、市話與手機名單（`build_landline_frame`、`build_mobile_frame`）、`simple_random_sample`、`landline_sample`、`mobile_sample` |
| `poll` | `PollResult`（各候選人、年齡層、年齡 × 候選人人數，以及設計權重總和）、`tally`、母體真值計算 |
| `experiment` | `run_experiment`：以指定抽樣方法重複執行民調 |
| `estimate` | `Estimate`、未加權、年齡加權、多重性加權、多重性 + 年齡加權估計，以及 Kish 有效樣本數 |
| `stats` | `summarize`：彙整多次估計的偏差、誤差範圍、涵蓋率等 |
| `main.cpp` | 串接上述模組並印出結果 |
