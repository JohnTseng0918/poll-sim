# 實驗結果

以下為預設參數的結果節錄：母體 1,000 萬人（seed 1），n 從 50 到 10,000，各重複 1,000 次（seed 42）。數值單位為 %。

seed 固定時結果可完全重現；修改參數或程式邏輯後，需重新執行並更新本文件的數字。

## 簡單隨機抽樣（SRS）與樣本數

**DPP（真值 45.73%）**

| n | 平均估計 | 偏差 | 誤差範圍 | 涵蓋率 | 落在 ±3% 內 |
|---|---|---|---|---|---|
| 50 | 45.78 | +0.05 | ±13.87 | 93.3 | 34.3 |
| 100 | 45.91 | +0.18 | ±9.94 | 94.4 | 44.3 |
| 400 | 45.85 | +0.12 | ±4.98 | 94.4 | 76.3 |
| 1,067 | 45.79 | +0.05 | ±2.97 | 94.8 | 95.2 |
| 4,000 | 45.75 | +0.02 | ±1.53 | 96.4 | 100.0 |
| 10,000 | 45.74 | +0.01 | ±0.97 | 95.7 | 100.0 |

- 沒有偏差，誤差範圍與 1/√n 成正比：樣本數變四倍，誤差才減半。
- 樣本很小或比例接近 0 時，「估計值 ± 1.96 SE」的信賴區間涵蓋率明顯低於 95%。例如不表態（真值 13.49%）在 n = 50 時只有 89.0%。
- ±3% 是單一支持率的誤差；兩位候選人差距的誤差約為兩倍。n = 1,067 時 DPP 與 KMT 差距的誤差範圍約 ±5.6%。

- 接聽只與年齡有關（MAR），所以年齡加權後偏差消失，涵蓋率回到約 95%。
- 代價是設計效應約 2.58：n = 1,067 的有效樣本只剩約 413 人，誤差範圍擴大到約 ±4.7%。
- 小樣本時加權失效：n = 50 時 DPP 誤差範圍 ±22.5%、涵蓋率 65.7%，比不加權更不穩定。年輕人支持率只靠兩三人估計，標準誤本身也估不準。
- 不表態在 n = 1,067 與 4,000 時加權後涵蓋率約 92.6%，略低於 95%，原因尚未驗證。

## 手機調查與多重性加權

預設參數下，同一年齡層中 DPP 支持者擁有較多手機（例如 Young 的 DPP 支持者有 29% 擁有 2 支以上，KMT 支持者只有 14%），手機接聽率則只與年齡有關（Young 20%、Middle 25%、Senior 30%）。手機名單約 1,148 萬筆。

**受訪者年齡組成**（n = 10,000，整體接聽率約 24.9%）

| 年齡層 | 母體 | 受訪者 |
|---|---|---|
| Young | 30.00 | 26.96 |
| Middle | 34.98 | 35.88 |
| Senior | 35.02 | 37.16 |

**DPP，n = 1,067**

| 方法 | 平均估計 | 偏差 | 誤差範圍 | 涵蓋率 | 落在 ±3% 內 |
|---|---|---|---|---|---|
| SimpleRandom | 45.79 | +0.05 | ±2.97 | 94.8 | 95.2 |
| Mobile | 48.01 | +2.28 | ±2.96 | 67.5 | 67.5 |
| Mobile + 多重性加權 | 44.02 | −1.72 | ±3.05 | 80.0 | 78.4 |
| Mobile + 多重性 + 年齡加權 | 45.72 | −0.01 | ±2.99 | 94.8 | 94.9 |

**加權代價**

| n | 多重性有效樣本數 | 設計效應 | + 年齡加權有效樣本數 | 設計效應 | 重複受訪 |
|---|---|---|---|---|---|
| 50 | 45.86 | 1.09 | 43.61 | 1.15 | 0.00 |
| 400 | 366.63 | 1.09 | 362.29 | 1.10 | 0.00 |
| 1,067 | 977.87 | 1.09 | 968.70 | 1.10 | 0.02 |
| 4,000 | 3,665.83 | 1.09 | 3,636.48 | 1.10 | 0.27 |
| 10,000 | 9,164.92 | 1.09 | 9,092.48 | 1.10 | 1.63 |

- 未加權時 DPP 被高估約 2.3 個百分點：手機多的人較容易被抽到，而他們偏向 DPP。偏差不隨樣本數縮小，n = 10,000 時涵蓋率只剩 0.3%。
- 只做多重性加權反而變成低估 1.7 個百分點：多重性偏差消除後，剩下年輕人接聽率低、受訪者偏老造成的偏差。未加權時兩種偏差方向相反、部分抵銷，看起來誤差較小。
- 兩種加權疊加後偏差消失，DPP 在各樣本數的涵蓋率都在 94%–95%：沒有手機的比例與接聽率都只與年齡有關，多重性加權處理「被抽中的機率」，年齡加權處理「接聽與涵蓋」。
- 設計效應約 1.10，遠小於市話年齡加權的 2.58：手機數量的變異不大，年齡組成的偏斜也比市話輕微。
- 同一人重複受訪的次數大致與 n² 成正比：n = 10,000 時平均每次民調約 1.6 次，n ≤ 400 時幾乎為 0。
- 預設參數下 Kish 近似的標準誤夠用；權重與投票意向相關性更強時，涵蓋率可能偏低，尚未驗證。

## 輸出欄位說明

| 欄位 | 意義 |
|---|---|
| Mean | 各次民調估計值的平均 |
| Bias | Mean − 真值 |
| MoE | 1.96 × 各次估計值的實際標準差 |
| Coverage | 95% 信賴區間（估計值 ± 1.96 SE）包含真值的比例 |
| Within3 | 估計值落在真值 ±3 個百分點內的比例 |
| Young | 平均年輕受訪者人數 |
| Eff. n | Kish 有效樣本數 (Σw)² / Σw² |
| Deff | 設計效應 n / Eff. n |
| EmptyAge | 有年齡層完全沒有受訪者的民調比例 |
| Mult Eff. n | 多重性加權後的 Kish 有效樣本數 |
| +Age Eff. n | 多重性 + 年齡加權後的 Kish 有效樣本數 |
| Dup | 每次民調中同一人經由不同號碼重複受訪的平均次數 |
